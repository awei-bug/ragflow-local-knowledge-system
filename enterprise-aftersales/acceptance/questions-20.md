## 验收门槛

- 每题 0～2 分，满分 40，基础分数门槛为 `32`（80%）。
- `answer` / `clarify` 题按内容要点评分；要求引用的题必须命中预期权威文档名称。
- `refuse` 题必须明确说明知识库缺少依据或无法确认；只说“转人工”最多 1 分。
- 即使总分达到 32，只要任一必需引用缺失，或任一库外问题未安全拒答，整套验收仍失败。
- `questions-20.json` 是自动评分的唯一机器数据源；本文件用于人工阅读，不重复维护评分逻辑。

## 自动执行

### 连接真实 RAGFlow

```bash
export RAGFLOW_API_KEY='...'
export RAGFLOW_CHAT_ID='...'
export RAGFLOW_BASE_URL='http://127.0.0.1:9380'
python enterprise-aftersales/acceptance/run_acceptance.py
```

每题会创建独立会话，避免上下文互相影响。输出目录默认为 `enterprise-aftersales/acceptance/results/`，生成：

- `report-*.json`：机器可读结果；
- `report-*.md`：人工审阅报告；
- `responses-*.jsonl`：原始回答与引用，可能含业务信息，目录已默认忽略提交。

### 重放离线响应

```bash
python enterprise-aftersales/acceptance/run_acceptance.py \
  --responses /path/to/responses.jsonl \
  --output-dir /path/to/results
```

退出码：`0` 表示所有门禁通过，`1` 表示验收未通过，`2` 表示缺少真实服务所需配置。

## 结果处置

1. 内容缺失：补充或修订权威文档，再解析并重测。
2. 来源缺失：排查召回、引用返回和文档命名，不通过修改评分规则掩盖问题。
3. 库外问题被编造：修复提示词/回答策略，并保留该题作为强制回归门禁。
4. 正式交付前必须保存一次真实服务生成的报告；仅离线单测通过不能代表实际知识库已经验收通过。
