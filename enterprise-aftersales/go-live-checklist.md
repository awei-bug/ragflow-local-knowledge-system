# 售后场景上线清单

## A. 系统

- [ ] RAGFlow 可稳定访问
- [ ] Chat 模型可用（Agnes）
- [ ] Embedding 模型可用（通义等）
- [ ] 界面中文
- [ ] 管理员密码非默认弱口令

## B. 知识

- [ ] 已创建「售后支持库」
- [ ] P0 文档已入库并解析成功
- [ ] 过期文档已隔离
- [ ] 每份文档有 owner

## C. 质量

- [ ] 20 题验收完成
- [ ] 得分 ≥ 32/40
- [ ] 未覆盖问题会拒答
- [ ] 来源引用正常

## D. 权限与审计

- [ ] 客服账号仅可访问售后库
- [ ] 客服不能删除知识库
- [ ] 问答日志可查看

## E. 运营

- [ ] 指定知识管理员
- [ ] 每周未命中问题复盘 1 次
- [ ] 文档更新后有重解析流程
- [ ] 备份与恢复演练 1 次

## F. 试用

- [ ] 至少 3 名一线客服试用
- [ ] 收集 20 条真实用户问题
- [ ] 形成第一周改进清单
