# 知识库结构（售后支持库）

## 库名
售后支持库

## 建议分类（文件夹/标签）

1. `01-开机与硬件`
2. `02-网络与连接`
3. `03-系统与固件`
4. `04-退换货与保修`
5. `05-配件与兼容性`
6. `06-升级与迁移`
7. `07-工单升级规则`

## 文档命名规范

```text
[类别]-[主题]-[版本]-[日期].md
示例：04-退换货-七天无理由-v1.2-2026-07-01.md
```

## 入库规则

1. 只收“现行有效”文档
2. 过期政策单独进「归档」，默认不参与问答
3. 每个主题只保留一个当前版本
4. 必须有文档负责人（owner）

## 问答入口（对客服）

客服只需要：
1. 打开聊天
2. 选择「售后支持库」
3. 粘贴用户问题或现象
4. 复制系统给出的步骤 + 来源，回复用户
