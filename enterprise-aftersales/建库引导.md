# 售后支持库 — 页面建库引导（按这个点）

适用：RAGFlow 网页操作。  
目标：建好「售后支持库」，把示例文档导进去，能开始验收提问。

---

## 0. 前置检查

1. Docker Desktop 已启动
2. 浏览器能打开：http://127.0.0.1:8088  
   （若没启动，到源码仓库 `docker` 目录按 README 启动）
3. 已登录（如 admin@local.test）
4. 模型可用：
   - Chat：agnes-2.0-flash（Agnes，Base URL=`https://apihub.agnes-ai.com/v1`）
   - Embedding：text-embedding-v3（通义等，必须有）

> 没有 Embedding，文档会上传成功但解析/检索容易失败。

---

## 1. 创建知识库

1. 左侧进入 **知识库 / Knowledge Base**
2. 点击 **创建知识库 / Create**
3. 填写：
   - 名称：`售后支持库`
   - 描述：`一线客服售后 SOP、政策、兼容与升级规则`
4. 解析/切片相关选项：
   - 语言：中文
   - 权限：仅团队内可见（不要公开）
5. 保存

---

## 2. 按分类上传文档（关键）

把下面目录中的文件上传到「售后支持库」：

```text
enterprise-aftersales/sample-docs/
  01-开机与硬件/
  02-网络与连接/
  03-系统与固件/
  04-退换货与保修/
  05-配件与兼容性/
  07-工单升级规则/
```

完整路径：

```text
F:\Python_code\RAG 本地知识库问系统\enterprise-aftersales\sample-docs
```

### 上传建议

- 可以一次多选上传全部 `.md`
- 若系统支持文件夹/标签，按 `01`~`07` 分类
- 上传后等待状态变为 **解析成功 / Success / 可用**

---

## 3. 配置助手（聊天）

1. 左侧进入 **聊天 / Chat / 助手**
2. 新建助手/对话
3. 关联知识库：勾选 **售后支持库**
4. 将 `enterprise-aftersales/prompt-policy.md` 中的规则粘贴到系统提示词
5. 默认模型选：
   - Chat：agnes-2.0-flash
   - 检索来源：售后支持库

---

## 4. 建库后立刻做的 5 个冒烟问题

解析完成后，逐条问：

1. 开机无反应怎么排查？
2. 七天无理由退货需要哪些条件？
3. 固件升级失败怎么回退？
4. 保修期内进液能免费修吗？
5. A100 和 A90 电源兼容吗？

每题检查：
- 步骤是否可执行
- 是否有来源
- 有没有乱编

完整 20 题见：`enterprise-aftersales/acceptance/questions-20.md`

---

## 5. 你在页面上应看到的最终状态

- 知识库列表里有：`售后支持库`
- 文档数量 ≥ 9
- 文档状态均为解析完成
- 聊天已绑定该库
- 提问能返回带引用的步骤答案

---

## 6. 常见卡住点

| 现象 | 处理 |
|---|---|
| 不能创建知识库 | 是否登录、是否管理员 |
| 上传后一直解析中 | 查 Embedding 是否配置成功 |
| 能上传但问答胡说 | 助手没绑定「售后支持库」或提示词没设拒答 |
| 全是英文界面 | 头像设置里改 Chinese / 简体中文 |
| 8088 打不开 | Docker 没启动或 compose 未 up |

---

## 7. 做完回我什么

回我这 4 项即可继续验收：

1. 知识库是否创建成功  
2. 上传了多少个文件  
3. 解析是否全部成功  
4. 冒烟 5 题里哪几题不对
